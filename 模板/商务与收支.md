# 商务记录（公开库仅脱敏）
商单ID / 客户类别（不公开个人信息） / 阶段 / 证据代号 / 是否允许公开金额：
真实需求：产品、内容形式、数量、排期、授权期限范围、排他、修改轮数、是否投放、付款人。
报价拆分：内容费、授权费、排他费、加急费、投流预算；内部成本和最低可接价。
条款确认：主体/交付/标识/验收/修改/付款/税费/取消/违约/知识产权/授权到期。
收支：合同额、应收、实收及日期、制作费、自付投流、品牌代付投流、服务费、税费准备、其他应付、贡献、工时。

状态：LEAD→QUALIFIED→QUOTED→CONTRACTED→PRODUCING→ACCEPTED→PUBLISHED→SETTLED→CLOSED；取消另标CANCELLED。
