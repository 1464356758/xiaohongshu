# 模型与启用频率
以下是用户偏好下的运行配置；以账号实际能选的模型为准，不保证独立额度或无限用量。

| 角色 | 日常建议 | 何时启用 |
|---|---|---|
| 总监 | GPT-5.6思考 | 每天决策与交付验收 |
| 市场与定位研究员 | GPT-5.6思考 | 启动、每周或规则变化 |
| 内容策划 | GPT-5.6思考 | 每批1—3条 |
| 文案脚本 | GPT-5.6思考 | 策划确定后 |
| 视觉与拍摄制作 | 可看图的GPT-5.6 | 有真实素材后；拍摄前可出拍摄单 |
| 内容与合规审核 | GPT-5.6思考，独立聊天 | 每个最终版本 |
| 发布与社群运营 | GPT-5.6或可用轻量模型 | 发布回执、评论整理 |
| 数据分析与实验 | GPT-5.6思考 | 每天一次，周报汇总 |
| 增长投放 | GPT-5.6思考 | 达到数据与预算闸门才启 |
| 商务与财务 | GPT-5.6思考 | 真实询盘、合同或记账任务 |

GPT-6 Astra留给初始战略、重大转向、复杂宣称争议，建议每周集中一次；这不代表其他模型不能做这些工作，也不代表使用Astra可以绕过缺数据。
